# Hello World

A small HTML/CSS learning project, originally created from GitHub's first-website tutorial.

## View it locally

Open [index.html](index.html) in a browser. No package installation, build step or backend is required. The page loads an Octocat image from an external URL, so that image requires an internet connection.

## Files

| Path | Purpose |
| --- | --- |
| [index.html](index.html) | Page markup and content |
| [styles.css](styles.css) | Page styling |
| [images/](images/) | Image supplied with the original tutorial |

Edit the HTML or CSS, save, and reload the browser to see changes.

This is a learning repository rather than a portfolio. GitHub Pages is not currently enabled; the repository name alone does not publish a website.
